Web Calculator
An interactive and user-friendly web calculator developed using HTML,
CSS, and JavaScript as part of the Oasis Infobyte Web Development
and Designing Internship.

Project Description
The Web Calculator performs basic arithmetic operations through a simple
interface. Users can enter numbers and operators using the on-screen
buttons and view their calculations in the display.

The project demonstrates front-end development concepts such as HTML
page structure, CSS styling, JavaScript event handling, and DOM
manipulation.

Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)
- Clear (C) and delete (DEL) controls
- Decimal number input
- Interactive calculator buttons

Technologies Used
- HTML5 -- Structures the calculator interface.
- CSS3 -- Styles the calculator and its buttons.
- JavaScript -- Handles button interactions and calculation logic.
  
Project Structure
Web-Calculator/
├── index.html
├── style.css
├── script.js
└── README.md

Keep index.html, style.css, and script.js in the same folder so
the stylesheet and JavaScript file load correctly.

Run Locally
1. Download or clone this repository.
2. Make sure all three project files are in the same folder.
3. Open index.html in a web browser.
